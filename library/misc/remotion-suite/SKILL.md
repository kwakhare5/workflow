# Remotion Video & Motion UI Suite

Complete toolkit for building, previewing, and rendering programmatic videos and motion UI with React and Remotion.

## Sub-modules & Commands

1. **/remocn**: Copy-paste animated components, timelines, and UI motion primitives from shadcn registry.
   - Reference: `references/remocn.md`
2. **/remotion-create**: Scaffolding new video compositions, canvas animations, and frame-accurate timelines.
   - Reference: `references/remotion-create.md`, `references/remotion-markup.md`
3. **/remotion-studio**: Previewing compositions in the local Remotion Studio UI.
   - Reference: `references/remotion-studio.md`
4. **/remotion-render**: Server/CLI rendering to MP4, WebM, GIF, or transparent PNG sequences.
   - Reference: `references/remotion-render.md`
5. **Captions & Multimedia**: Audio waveforms, automated subtitles, and Mediabunny integration.
   - Reference: `references/remotion-captions.md`, `references/remotion-multimedia.md`
