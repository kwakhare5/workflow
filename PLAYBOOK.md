## 1. The Engineering Loop

Follow this workflow for non-trivial features, refactors, and bug fixes:

```
1. Grill Plan       -->  skill: grill-with-docs (/grill-with-docs)
2. Design Seams     -->  skill: codebase-design
3. Lock Spec        -->  skill: to-spec (/to-spec)
4. Create Tickets   -->  skill: to-tickets (/to-tickets)
5. Build Test-First -->  skill: implement & skill: tdd (/tdd)
6. Debug / Repro    -->  skill: diagnosing-bugs (/diagnosing-bugs)
7. Code Review      -->  skill: code-review (/code-review)
8. Verify           -->  skill: verify-<project> (via create-verification-skill)
9. Ship             -->  skill: pr (/pr)
10. Handoff         -->  skill: handoff (/handoff)
```

| Step | Skill & Command | What It Does | Example Prompt |
|---|---|---|---|
| **1. Grill Plan** | `grill-with-docs` (`/grill-with-docs`) | Socratic interview that kills assumptions and generates `GLOSSARY.md` + ADRs. | *"Grill me on adding Stripe subscriptions"* |
| **2. Design Seams**| `codebase-design` | Deep module design; runs "Design it twice" on critical interfaces. | *"Design the interface for our order processor"* |
| **3. Lock Spec** | `to-spec` (`/to-spec`) | Synthesizes agreements into a frozen spec with requirements & out-of-scope. | *"/to-spec lock this into a feature spec"* |
| **4. Create Tickets** | `to-tickets` (`/to-tickets`) | Slices spec into vertical tracer-bullet tasks with dependency blocking edges. | *"/to-tickets break this spec into tasks"* |
| **5. Build** | `implement` / `implement-spec` | Builds tickets test-first in isolated git worktrees. | *"Build ticket 01 using TDD"* |
| **6. Debug** | `diagnosing-bugs` (`/diagnosing-bugs`) | 4-step bug diagnosis: isolate, repro test first, root cause fix once, verify. | *"Diagnose why checkout webhook times out"* |
| **7. Review** | `code-review` (`/code-review`) | Dual sub-agents: Agent 1 audits coding rules, Agent 2 audits spec match. | *"/code-review audit my branch diff"* |
| **8. Verify** | `verify-<project>` | Drives feature via real app runner (generated by `create-verification-skill`). | *"Run verification for checkout flow"* |
| **9. Ship** | `pr` (`/pr`) | Drafts clean PR body text with test proof (pushes nothing). | *"/pr draft PR for this branch"* |
| **10. Handoff** | `handoff` (`/handoff`) | Compacts session context to `.scratch/HANDOFF.md`. | *"/handoff summarize for next session"* |

## 2. Global Skills Catalog (28 Active Skills)
